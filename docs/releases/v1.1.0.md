# Multi-Model AI Orchestrator v1.1.0

In-place GitHub Automation Engine on top of v1.0.0. Not published until review.

## Added

- Optional `manual` / `assisted` / `autonomous` repository modes (default manual; no auto-merge or publish)
- `.github/ai-orchestrator.yml` validation that fails closed
- Trusted-actor `ai-auto` gate, labels, Issue form, `ai-issue.yml` self-hosted workflow
- CLI: `github issue run|inspect`, `labels setup`, `status`, `resume`, `simulate`, `--dry-run`
- CI watch, bounded 5-attempt fix loop, run state under LocalAppData
- Docs under `docs/` for installation, automation, security, and troubleshooting

## Unchanged

`/ai` skills, smart routing, TEAM loop, worktree isolation, `--task-file` transport, global CLI, Windows spawning.
